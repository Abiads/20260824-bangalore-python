# CDAC Python Course Assignments & Exercises

This repository contains the complete curriculum, class workspaces, notes, datasets, and structured practice assignments for the **Advanced Programming Using Python** course at CDAC Bengaluru. Maintained by **Abs6187** (CDAC Bengaluru AI student).

> **[Abs6187](https://github.com/Abs6187)** is the primary/real GitHub account. The **[Abiads](https://github.com/Abiads)** account is used here for training and continuous practice.
